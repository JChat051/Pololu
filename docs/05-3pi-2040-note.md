# Using a 3pi+ 2040 instead?

This repository is written for the **3pi+ 32U4**. The **3pi+ 2040** is a newer robot built on the RP2040 chip, and it is set up differently:

- Different board package (the Arduino Mbed OS RP2040 boards package).
- A different library (the official 2040 robot ships with MicroPython; Arduino support is via a **community-made port** of the 32U4 library, which is not an official Pololu product).
- Example sketches live under a different name in **File > Examples**.

The *concepts, track designs, challenges and timings* in this repo all still apply. Only the **setup step** (`docs/02-arduino-ide-setup.md`) and the sketch names/variables will differ.

Before running a session with 2040 robots, follow the setup instructions in whichever library you choose, test the example, and update the setup page for your students. Also note: if you want to return a 2040 to MicroPython afterwards, the Pololu user's guide explains how to reflash the firmware.
