# Preparation Checklist

## 1-2 weeks before

- [ ] Confirm numbers of students, robots (1 per pair), laptops (1 per pair), and helpers.
- [ ] Check every robot: powers on, motors turn, sensors read, USB cable works.
- [ ] Confirm each robot's **edition** (Turtle / Standard / Hyper) and label them.
- [ ] Order **spare** AAA batteries (rechargeable NiMH recommended) and USB **data** cables.
- [ ] Decide whether laptops are **student-owned** or **pre-configured**. Strongly prefer pre-configured.
- [ ] Venue: confirm floor space for two tracks, power sockets, and Wi-Fi (or plan for offline).

## Laptops

- [ ] Arduino IDE 2.x installed
- [ ] Boards Manager URL added and **Pololu A-Star Boards** installed
- [ ] **Pololu3piPlus32U4** library installed
- [ ] Hello sketch uploaded successfully to a robot **from this laptop** (this tests drivers and permissions too)
- [ ] Linux only: user is in the `dialout` group
- [ ] Managed/school machines: confirm you have install rights, or ask IT to image them

## Robots

- [ ] Fresh batteries in all robots, plus a charged set per two robots
- [ ] Sensors wiped clean with a dry cloth
- [ ] Number each robot and its USB cable

## Tracks (see `track-design.md`)

- [ ] Track A (oval) built and tested
- [ ] Track B (S-bend) built and tested
- [ ] Run the example yourself and record safe / fast / break-point speeds on both tracks

## Printing

- [ ] One worksheet per pair (`worksheets/student-worksheet.md`)
- [ ] One copy of `docs/02-arduino-ide-setup.md` per pair (or a QR code to the repo)
- [ ] Track map and race rules for the wall

## On the day

- [ ] Arrive 45 minutes early; lay tracks, power up one robot to test lighting
- [ ] Test calibration on the track under the room's lighting
- [ ] Hand out robots and laptops; keep spares at the front
- [ ] Safety brief: robots near edges, tape trip hazards, no touching sensors
